# Arcora 使用指南

## 构建和启动

系统要求：macOS 14+，Xcode 15.3+ / Swift 5.10+，Python 3。构建前运行一次 Xcode 并接受开发许可。

```bash
./Scripts/bootstrap-engines.sh
./Scripts/build-app.sh
open dist/Arcora.app
```

应用将出现在 `dist/Arcora.app`。`dist` 是构建目录，不要把需要保留的业务数据放入里面。此处默认使用本地 ad-hoc 签名；公众分发另见 RELEASE.md。

### 离线构建

更新源码包已提供 macOS universal 依赖，可直接运行 `bash Scripts/build-app.sh` 离线构建。若要从头重建依赖，在缓存目录准备 `Vendor/engines.lock.json` 中的 `7z2603-mac.tar.xz`、`7z2603-src.tar.xz`、`libarchive-3.8.9.tar.xz`、`xz-5.8.3.tar.gz` 四份固定原始文件，保留原名。

```bash
OFFLINE=1 ARCORA_DOWNLOAD_CACHE=/path/to/cache ./Scripts/bootstrap-engines.sh
./Scripts/build-app.sh
```

无论是否离线都验证锁文件中的 SHA-256。缺失文件或摘要不匹配会中止，不自动降级到未验证引擎。离线 Mac 仍需已安装完整开发工具。构建完成的 App 包含引擎；日常压缩解压不需要网络。

## 打开与浏览

将压缩文件拖入窗口，或按 ⌘O。支持的文件可通过 Finder 的“打开方式”选择 Arcora。文件夹或一组普通文件拖入窗口会进入新建压缩包。

表格展示名称、原始大小、压缩后大小和修改日期；不同格式并不总能提供压缩后大小，缺失时显示横线。双击目录进入子目录，面包屑返回上级。搜索范围依据当前模型显示整个档案匹配结果。点列表标题排序。右键可解压选中项目或复制路径。

对普通文件可手动 Quick Look 预览。预览会把选中文件真实解压到当前会话的私有临时目录，不执行文件；默认限制为 100 MiB。关闭预览时清理文件。异常退出、掉电或操作系统交换内存不属于可保证清理范围，敏感文件请谨慎预览。

## 创建压缩包

按 ⌘N 或“新建”，添加文件或目录，选择目标目录和名称。普通创建会保存输入项本身的名称；多项输入通过受控的列表文件传给引擎。

格式决定参数：7z 使用 LZMA2；ZIP 默认 Deflate，可选择 AES-256 或兼容性较强但较弱的 ZipCrypto；TAR 只打包、无压缩；GZ / BZ2 / XZ 单流格式只接受一个普通文件。多个文件需要使用对应 TAR 组合格式。

压缩等级取格式支持值；0 表示存储模式而非高级压缩。字典单位为 MiB，只在支持自定义字典的格式启用。字典和线程增大会提高资源需求，不保证压缩率或速度总是改善。提交前以保守估算检查内存预算。

7z / RAR 可选择固实压缩；开启通常有利于相似小文件压缩率，但随机访问和选中项解压可能要扫描更多数据。默认创建后校验；关闭该选项只跳过内容完整性复检，不会跳过输出事务和基础安全检查。

## 密码与加密

创建时输入并确认密码。打开加密文件时会请求密码。密码不作为子进程命令行参数，不进入历史记录，也不保存到配置文件；应用会尽力清理内存缓冲区。但 Swift 字符串、系统输入控件、交换文件和崩溃转储不能做到绝对无副本，请勿将其理解为密码保险库。

7z 可以加密文件名；ZIP 不提供等价文件名隐藏功能。RAR 在接入官方工具后可启用文件名加密。空密码按“不加密”处理；控制字符和超长密码被拒绝。RAR 适配器另限制不超过 127 个 UTF-16 代码单元，防止上游截断。

ZIP 创建受上游限制只支持 ASCII 密码，AES 密码不超过 99 字节。需要中文、日文或 emoji 密码时请选择 7z 或 RAR；应用会在提交前提示，不会静默替换密码。

压缩文件夹名称或目标路径本身可能是敏感信息；最近文件和任务历史会保存路径，可在设置中清除。

## 分卷

在 7z、ZIP 或 RAR 创建设置中启用分卷，填写如 `100 MiB`、`2 GiB`；最小 64 KiB。分卷大小为每卷的上限目标，最后一卷可以较小。

为了避免只有部分卷被提交到目标目录，创建完成后会将整套文件放入一个目录，例如：

```text
backup.7z.parts/
  backup.7z.001
  backup.7z.002
  backup.7z.003
```

分发时保留全部分卷和原始名称。它们是标准引擎生成的分卷，不是 Arcora 私有文件格式。ZIP 的数字分卷是 `.zip.001` 这种流拆分，不等同于传统 PKZIP `.z01`；接收方需要支持此类分卷的工具。

解压时将所有卷放在同一个目录，可以选择首卷，也可以选择支持命名规则下的中间卷，Arcora 会定位起始卷并检查已发现序号的连续性。缺少末卷无法仅从目录名称判断，最终由引擎确认并报错。不要把多个不同档案、相同前缀的分卷混放。

## 解压

打开档案后按 ⌘E，选择目标位置和新目录名称。默认总是在一个独立目录中提交结果，不把未验证内容直接混入用户现有目录。

同名策略：自动编号或报错；不覆盖已有文件。选中解压只提交选择的文件与目录树。条目存在路径穿越、链接、特殊设备、规范化后重名等风险时安全失败，不“尽量猜测后继续写入”。这也意味着某些 Unix 备份不能原样还原，详见 FORMAT_SUPPORT.md。

## 活动与性能

侧栏“活动”显示等待、运行、暂停、成功和失败状态。可以暂停 / 继续 / 取消。正常取消会中止工作进程并清理未提交结果；无法自动恢复到断点继续，需要重新开始。

“设置 → 性能”控制并行任务数、总线程预算和估算内存预算。“安全”限制最大解压后容量和文件数量。默认容量 200 GiB、条目 250,000。内存是调度估算而非强制进程 RSS 上限，某些格式字典和引擎额外分配可能超出估值。

原生 libarchive 路径流式处理文件，不将解压内容整体加载到内存。7-Zip / RAR 实际内部并行度由格式和引擎决定；不能将一个串行流通过界面参数强制变为任意多线程。

失败时显示本地化分类和引擎诊断。错误密码不会作为成功提交。重试需要任务仍有当前会话的执行信息；重新启动后的历史用于审计状态，不承诺重放或恢复执行。

## RAR 创建

RAR4/RAR5 浏览、校验和解压开箱即用，不需要 RAR 编码器或许可证。创建 RAR 采用客户取得的官方原包和自己的许可证；产品不随附两者。

设置 → 引擎：① 点击“打开官方下载”，浏览器会打开当前 Mac 架构对应的 RARLAB 原包链接；② 下载后点击“导入原包并配置”，选择原始 .tar.gz，不要手工解压或重新打包；③ 导入自己购买的 rarreg.key，确认使用权覆盖本机。官方引擎确认注册后，可以创建 RAR5，使用密码、文件名加密、固实、分卷和创建后校验。无需终端、Homebrew 或管理员安装。

导入只接受固定官方版本和正确架构的完整原包，并核对 SHA-256。失败保留旧配置，源文件不变。浏览器若自动解压，请保留或恢复原始下载文件，不要重新压缩。Arcora 不在后台下载、不提供镜像、不清除 macOS 隔离标记；系统可能要求用户批准运行。许可证只保存在本机私有目录；未导入或核验失败时创建保持锁定，解压不受影响。详情见 RAR_DELIVERY.md 和 RAR_LICENSES.md。

## 语言、隐私和维护

设置中选择简体中文、English、日本語或跟随系统，应用内容立即切换。Finder 服务标题由系统应用资源语言决定，可能需要重启应用或 Finder。技术文件名、格式名、第三方诊断原文和许可正文不强行翻译。

任务历史位于 `~/Library/Application Support/Arcora/history.json`；偏好与最近文件保存在应用 UserDefaults。当前会话临时目录名称为 `.arcora-UUID` 和 `Arcora-previews-UUID`。正常结束清理自己的目录，不会扫描删除其他未知目录。发生崩溃后，确认 Arcora 和工作进程都已退出再手动清理遗留目录。

本地操作不包含上传、广告、远程脚本或自动更新。引擎升级需维护者重新审核版本、更新锁文件、执行集成与 macOS 验收后重新发布。macOS 包静态链接固定的 libarchive 3.8.9 与 liblzma 5.8.3，不依赖 Homebrew；维护者需随应用更新这些组件。
