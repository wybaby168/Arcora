# macOS 正式发行验收清单

本文件保留完整的正式发行检查范围，不因本机集成测试通过而自动勾选。2026-09-08 已完成 macOS SDK 双架构构建、Apple Silicon 本机及 Rosetta 集成运行，具体结果见 TEST_REPORT.md。独立 Intel 真机、最低系统、商用授权、下载后 Gatekeeper 和压力场景仍须逐项记录。

## 构建与加载

- [ ] Xcode 15.3 / Swift 5.10 或选定生产工具链完整编译 SwiftUI / AppKit / C。
- [ ] arm64 和 x86_64 Universal 三个自有程序及 7zz 架构验证通过。
- [ ] Apple Silicon 原生启动，Intel 实机或等价可靠环境原生启动，不把 Rosetta 运行当成 Intel 原生验收。
- [ ] 三语资源 Bundle、InfoPlist.strings、图标、许可和对应引擎源码都在 App 内。
- [ ] Developer ID、hardened runtime、notarization、staple、Gatekeeper 下载路径均通过。
- [ ] macOS 14 上静态 libarchive / liblzma 与 SDK 动态依赖实际运行通过。

## 主流程

- [ ] 普通 ZIP、7z、RAR / RAR5、TAR 组合格式打开 / 浏览 / 搜索 / 选中提取 / 完整提取。
- [ ] 所有九类非商业写入格式往返后逐文件 SHA-256 一致。
- [ ] 7z / ZIP Unicode 密码，错误密码，无密码，头加密，密码中含非 ASCII 字符。
- [ ] RAR：官方链接架构正确（含 Rosetta），原始 .tar.gz 导入/替换/损坏拒绝；客户自己的真实许可证注册、目录递归、空文件、固实、加密头、字典和分卷往返。
- [ ] 7z / ZIP / RAR 多卷从首卷和中间卷打开；缺中间卷 / 缺末卷 / 损坏卷失败且无半成品提交。
- [ ] 空目录、中文、日本語、emoji、空格、长路径、隐藏文件、源文件名以连字符或 @ 开头。
- [ ] 经典 RAR 4.x、现代 RAR 大字典、额外只读格式按最终宣传清单提供具体样例和结果。

## 交互与性能

- [ ] 浅 / 深色与三语 UI 无截断，⌘N/O/E/T、VoiceOver 基本可用。
- [ ] Finder 打开方式、Services 压缩入口、拖放、选择多个文件、剪贴板和 Finder reveal。
- [ ] Quick Look 预览 100 MiB 限制、关闭清理、切换档案取消旧预览。
- [ ] 同时提交多个大任务，线程 / 并行数预算正确，任务状态无竞态。
- [ ] 暂停 / 恢复 / 取消 / 关闭应用 / 错误后重试；无残留运行的受控工作进程。
- [ ] 大于 10 GiB 文件和超过 100,000 条目的真实档案，测量峰值 RSS、磁盘放大、首屏与搜索响应。
- [ ] 非串行可并行格式确实按引擎能力使用线程；记录 CPU / 速度，不承诺所有格式均线性扩展。

## 安全、文件系统与故障

- [ ] Zip Slip、绝对路径、嵌入 NUL、大小写 / Unicode 冲突、父文件冲突、符号 / 硬链接 / FIFO 全部安全失败。
- [ ] APFS 大小写不敏感与大小写敏感卷、外置盘、只读目录、权限不足、接近满盘场景。
- [ ] 目标同名自动编号 / 报错，原件内容不变；多卷作为整套目录提交。
- [ ] 展开容量 / 条目 / 日志上限、损坏档案、无效文件、超时、取消期间清理。
- [ ] 文件可执行位、修改时间和 quarantine 传播检查；记录不保留的 ACL / 资源分叉限制。
- [ ] `ps` / 任务历史 / 错误日志没有真实密码，预览明文的生命周期符合说明。
- [ ] 产品不包含 RAR 编码器/原包/许可证，没有自动下载器或镜像；原包和客户许可证只存在于客户本机私有目录，官方条款和商业席位要求已告知。
