# 格式支持与兼容性边界

本表区分实现能力、外部引擎能力和当前测试范围。应用不保证所有同名扩展文件都可用。格式变体、损坏、非标准写入器、压缩方法、加密方式和安全政策均可能造成拒绝。

## 主流格式

| 格式 | 列表 / 解压实现 | 创建实现 | 密码 / 分卷 | 当前交付验证 |
| --- | --- | --- | --- | --- |
| 7z | 内置官方 7-Zip；libarchive 回退 | 官方 7-Zip，LZMA2 / Copy | AES-256、可加密头、数字分卷 | 真实创建、Unicode 密码、分卷、解压往返通过 |
| ZIP | 内置官方 7-Zip；libarchive 回退 | 官方 7-Zip，Deflate / Copy | AES-256 / ZipCrypto；数字分卷 | 真实创建、ASCII 密码、分卷、解压往返通过 |
| RAR / RAR5 | 内置官方 7-Zip；libarchive 回退 | 官方 RAR 7.23 原包本地导入 + 客户自带许可证 | 密码、头加密、固实、现代分卷 | RAR4 读取、RAR5 创建/读取及异常回归通过，详见 TEST_REPORT.md |
| TAR | libarchive 优先 | 官方 7-Zip | 不提供密码或分卷创建 | 真实创建、原生读取、完整往返通过 |
| TAR.GZ / TAR.BZ2 / TAR.XZ | libarchive 优先 | 先 TAR 再压缩，官方 7-Zip | 不提供密码或分卷创建 | 三类真实创建、原生读取、完整往返通过 |
| GZ / BZ2 / XZ | 官方 7-Zip 单流读取 | 官方 7-Zip，只接受单个普通文件 | 不提供密码或分卷创建 | 三类单文件真实创建、读取、完整往返通过 |

创建界面提供 9 种不需要 RAR 商业工具的格式选项，外加可选 RAR，共 10 种。TAR 的等级固定为 0。RAR 等级会映射到官方工具实际支持的范围，而不是把 7-Zip 参数直接照搬。

字典参数仅针对支持它的格式：7z / XZ / TAR.XZ / RAR。ZIP Deflate 不提供任意大字典选项；GZip / BZip2 也不会伪装成 LZMA 字典。

7-Zip ZIP 创建只接受 ASCII 密码，AES 密码最多 99 字节；界面和核心会明确拒绝超出限制的密码。Unicode 密码请选 7z 或 RAR。RAR 创建输出为 RAR5，不提供旧 RAR4 编码。

## 额外只读格式

官方 7-Zip 的公开能力包含 ARJ、CAB、CHM、CPIO、DMG、ISO、LZH、LZMA、MSI、NSIS、RPM、UDF、WIM、XAR、Z 及多种磁盘 / 文件系统镜像。Arcora 使用相同原生引擎的列表与解压接口，并受 Arcora 元数据解析与安全策略约束。这些额外格式是**引擎支持范围内的只读接入**，不是每个格式都已取得样例并完成兼容性验收。

不要将打开磁盘镜像等同于挂载、运行安装器或完整还原磁盘权限。应用不执行档案内的程序。WIM 虽然上游可创建，本项目创建界面未开放 WIM 写入。

libarchive 回退显式启用 7zip / ar / cab / cpio / iso9660 / lha / rar / rar5（头文件版本允许时）/ tar / xar / zip 容器及可用过滤器。不启用可能从描述文本读取外部本地文件的 mtree 格式，也不对未知任意文件启用 raw 自动“成功”回退。

## 分卷兼容

7z / ZIP 创建使用 `.001`、`.002` 数字分卷；RAR 创建使用官方 `-v`。读取解析器识别数字后缀、`.partN.rar`、旧式 `.rar + .r00` 以及传统 ZIP 卷集合。创建 `.zip.001` 不代表创建 `.z01`。解压必须让引擎看到完整相邻卷集合。

文件名序号检查能发现已存在卷之间的空洞，不能从单一首卷文件名推断还未提供的末卷。最终成功以引擎返回状态和文件复检为准。丢失分卷不会被空文件或拼接猜测填补。

## 多线程的真实含义

应用有独立的任务并发预算，也会向 7-Zip / RAR 传入线程数。具体编码 / 解码器可能只使用部分线程，TAR 本身不压缩，某些压缩流必须串行解码。libarchive 的单个档案读取路径是流式串行，在独立工作进程中运行；可以并行处理多个档案，但不宣称其单流解压为多线程。

## 有意不实现或保守拒绝

- RAR 修复记录、REV 重建、SFX 创建、更新 / 删除现有档案内部条目、持续增量备份和断点续压未实现。
- 解压拒绝符号链接、硬链接、设备、FIFO、绝对路径、父级跳转、空字节 / 控制字符、冒号路径和规范化后的重名；保留普通目录 / 文件及可安全保留的可执行位、文件修改时间。
- 不保证保留 ACL、所有者、资源分叉、所有扩展属性或 Unix 链接语义；不是系统级无损备份还原工具。macOS quarantine 尽力从源传播。
- 不支持所有历史编码的无损文件名选择器。路径无法安全解析或不能表示时拒绝；正常 UTF-8 中日文有真实回归测试。
- 7-Zip 文本列表的歧义行被拒绝，不把不可靠解析结果当成完整安全证明。引擎仍需持续更新，未知漏洞不能由外层检查绝对消除。
