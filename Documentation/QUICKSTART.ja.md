# Arcora 1.3.0

macOS 14 以降に対応したネイティブ圧縮ツールです。Xcode と Python 3 で構築します。

```bash
bash Scripts/bootstrap-engines.sh
bash Scripts/build-app.sh
open dist/Arcora.app
```

Universal App は 7-Zip 26.03、libarchive 3.8.9、liblzma 5.8.3 を内蔵し、これらの形式に追加インストールは不要です。任意の RAR 作成には下記の初回設定が必要です。

Finder の右クリック圧縮は、アプリを Applications に移して一度起動すると利用できます。ファイルやフォルダーを選び、サービス → Arcora の ZIP・7z・RAR クイック圧縮を選択してください。元ファイルを残し、同じ場所に検証済みの暗号化なしアーカイブを作成します。同名の場合は番号を付け、上書きしません。パスワードや分割にはカスタム圧縮を使用します。メニューがない場合は設定 → 一般で Finder サービスを更新し、macOS のキーボードショートカット → サービスも確認してください。[Finder ガイド](FINDER_SERVICES.md)を参照してください。

RAR/RAR5 の参照・検証・展開はすぐに利用できます。作成には設定 → エンジンで Mac 対応の公式ダウンロードを開き、元の .tar.gz と購入した rarreg.key を取り込み、使用権を確認してください。手動展開、ターミナル、Homebrew、管理者インストールは不要です。RAR5、ソリッド圧縮、Unicode パスワード、名前の暗号化、分割に対応します。

本製品は RAR エンコーダーやライセンスを配布せず、ミラー配信やバックグラウンドダウンロードも行いません。固定ハッシュで原本と実行ファイルを検証し、改変・不一致は拒否します。macOS の安全機能は維持します。正規購入ライセンスによる有効化テスト、Developer ID 署名、公証、新規環境での受け入れは公開前に必要です。RAR_DELIVERY.md を参照してください。

リカバリレコード、REV、修復、自己解凍形式作成、既存アーカイブ内の編集は提供しません。ZIP 作成のパスワードは ASCII 文字（AES は 99 文字まで）です。日本語・絵文字のパスワードには 7z または RAR を使用してください。危険なパス、リンク、特殊ファイルは拒否します。

実際の検証結果は TEST_REPORT.md、使用方法は USER_GUIDE.md を参照してください。
